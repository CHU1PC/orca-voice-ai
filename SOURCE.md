# Source snapshot

This repository contains the Orca mobile source and its shared runtime dependencies
needed for the iPhone voice-output MVP. The baseline was extracted from
[`stablyai/orca` at `a57e027cb3894d2d84a7dfd2d32211699caffaf6`](https://github.com/stablyai/orca/commit/a57e027cb3894d2d84a7dfd2d32211699caffaf6).
It is a subset of the upstream monorepo, not a complete desktop distribution.
